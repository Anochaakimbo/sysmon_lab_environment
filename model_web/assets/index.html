01

อัปโหลดโมเดลที่ฝึกแล้ว

การโหลด pickle/joblib สามารถรันโค้ดในไฟล์บนเครื่องนี้ได้ จึงใช้เฉพาะไฟล์ที่คุณเชื่อถือ

เลือกไฟล์และยืนยันแหล่งที่มาเพื่อโหลด

ใช้ feature_names_in_ หรือ columns ในไฟล์ ถ้าโมเดลไม่มีชื่อฟีเจอร์ ต้องระบุลำดับเองให้ตรงกับชุดฝึก

  • รองรับ estimator, Pipeline หรือ dict ที่มี model และ scaler
  • โมเดลจำแนกใช้ 0 = ปกติ, 1 = การโจมตี; ตัวตรวจค่าผิดปกติใช้ -1 / +1
02

เลือกข้อมูลทดสอบ

ไม่มีคอลัมน์นี้ก็ทำนายได้ แต่จะไม่มีคะแนนประเมิน

หากใช้วิธีรวม Event หรือ preprocessing ต่างกัน ให้เลือก CSV ฟีเจอร์ที่เตรียมแล้ว

รูปแบบ CSV ที่รองรับ

ค่าเริ่มต้นใช้ CSV ฟีเจอร์ที่ชื่อคอลัมน์ตรงกับโมเดล โดยเรียงให้ตรงกับตอนฝึกอัตโนมัติ เพิ่ม label 0/1 เพื่อคำนวณคะแนนได้

โหมด Sysmon Event ต้องมี:

คอลัมน์เสริม (ไม่มีได้ แต่ฟีเจอร์ที่ได้จากคอลัมน์นั้นจะเป็นค่าคงที่):

ไม่มี platform ระบบตรวจ OS เองจาก path / User / EventID; ไม่มี run_id ใช้ host_name ถ้ามี

Event mode ใช้คอลัมน์ label ตามโค้ดวิจัย ส่วน Image และ session ไม่บังคับ

ข้อมูล Event ที่ขาดในไฟล์ระบุได้เมื่อทั้งไฟล์มาจากรอบทดลองเดียวเท่านั้น

ค่าเริ่มต้นใช้ predict() ของโมเดลโดยตรง
เลือกปรับเกณฑ์เมื่อต้องการใช้คะแนน predict_proba แทน

เลือกไฟล์เพื่อเริ่มทดสอบ
